# Number Pop — Standard 3 Math Game

> **Curriculum Focus:** Multiplication & Division  
> **Target Audience:** Standard 3 Learners (Primary School / Ages 8–9)  
> **Platform:** Web (Desktop & Mobile Responsive)

---

## 🎮 About the Game
Pop floating balloons with multiplication multiples and division factors before time runs out!

## 🛠️ Features
- **Curriculum-Aligned**: Designed specifically for Standard 3 Mathematics.
- **Audio & Visual FX**: Real-time Web Audio API synthesized retro sound effects.
- **Progress & High Scores**: Automatic local storage of badges, streaks, and best scores.
- **Full Independence**: 100% self-contained static HTML, CSS, and Vanilla JavaScript with no external build tools required.

---

## 📦 Deployment to GitHub Pages
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. The game will be live at `https://YOUR-GITHUB-USERNAME.github.io/numberland-number-pop/`.
